# chrono-persona

**面向长期陪伴 Agent 的记忆与状态系统。**
基于 MCP 协议，给没有跨对话记忆的 AI Agent 装上一套会沉淀、会遗忘、会回想的长期记忆，并让角色拥有一条**独立推进的生活流**——让每次新对话不是从零重建、而是接续上一次；而在没人对话时，角色的世界也仍在继续。

> 全程 AI 协作（Claude Code / Cursor）开发，3 个月从 0 到可长期自用：已稳定运行、承载 900+ 条活跃记忆与 370+ 个状态快照，覆盖**开发 → 部署 → 运维**完整闭环。

---

## 一、架构说明

系统刻意拆成**两条互不耦合的线**：

- **用户端 · 分层记忆** —— 系统*记住*了什么。
- **角色端 · 自主生活** —— 角色在两次对话之间*经历*了什么（后台轮询推进 `日程 → 环境 → 快照 → 关系活动 → 事件` 闭环，带熔断保护）。

**分层记忆（三层 + 稳定层按 `role` 细分）：**

| 层 | 记什么 | 边界 |
|---|---|---|
| 事件层 Event | 对话中发生的具体事件、状态快照 | 随时间衰减 |
| 感受层 Feel | 模型自己的感受、留下的疑问 | 独立衰减、独立检索 |
| 稳定档案层 Stable | 长期边界 / 共识 / 相处模式 / 珍贵锚点 | **豁免遗忘**；内部再分 `standing`（必注入）/ `evolving`（按新近上浮）/ `anchor`（仅可检索） |

**技术架构**：`MCP 客户端（Claude 等）⇆ FastAPI 服务 ⇆ {SQLite + Markdown 记忆桶 / 向量库 / 后台异步调度}`。检索走向量语义 + 关键词双通道混合融合；后台调度带熔断器，长期无人值守可用。

## 二、关键 Prompt 与 Vibe 思路

**Vibe / AI 协作开发**：整套系统用 **Claude Code / Cursor 驱动实现**——人负责架构判断、边界设计与评测验证，AI 负责落地。这本身就是"用 AI 把效率拉满、完成全栈 0→1 闭环"的实践。

**关键 Prompt 设计（产品内）**：
- **生活流生成 prompt（防幻觉硬约束）** —— 后台生成角色生活时，prompt 强制"**绝不编造真实用户的任何行动 / 话语 / 位置**，未知即'等待'"，并要求 LLM **对本段做自评**（`speculative_about_user`），违规段落下游打标、提示前台与用户确认。这是一套**防止 AI 虚构真人行为**的上下文安全设计。
- **启动注入包（breath_bundle）** —— 固定槽位结构（个人/关系/自由联想），在「信息量 vs token 成本 vs 相关性」之间做平衡；并按块埋点量化、把单次初始化注入从 ~43k 压到 ~21k 字符（−50%）。
- **稳定原则注入** —— `get_current_state` 把边界共识与关系原则注入上下文，区分"每轮必注入"与"按新近注入"。

## 三、AI 调用逻辑

- **Function calling / 工具调用** —— 通过 **MCP 工具集**（约 20 个工具）让模型在对话中主动调用 `get_current_state` / `breath` / `hold` / `recall_anchors` 等，完成记忆的读写与状态获取。
- **多模型 / OpenAI 兼容** —— 后台的环境、快照、日程、人格演化生成走 OpenAI 兼容 API，可配置切换 DeepSeek / Gemini / 任意兼容端点。
- **token 成本控制** —— LLM **预算硬上限** + **prompt-hash 去重**（同请求不重复花钱）+ 自动化 token 统计与按模型单价的成本估算。
- **上下文管理** —— 启动注入按固定槽位 + token 预算截断；注入成本按块量化并压缩 50%（见上）。
- **传输** —— MCP **Streamable HTTP / SSE**；后台调度带熔断器，连续失败自动暂停退避，避免故障时空转烧 token。

> 检索质量经评测验证：20 条真实 gold set、生产口径 A/B，**recall@5 20% → 85%、recall@10 35% → 100%**（McNemar p=0.0002，227 测试零回归）。

## 四、部署步骤（含 DNS / HTTPS）

**本地 / VPS 运行：**
```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml   # 填入 LLM api_base / api_key / model
python -m server.main                # 默认 :8000，含 Web 管理台 + MCP 端点
```

**公网接入 + HTTPS（Cloudflare Tunnel）：**
- 用 **Cloudflare Tunnel** 把本地 `:8000` 暴露到公网——**自动获得 HTTPS、无需手动证书、无需开放端口**。
- **DNS**：在 Cloudflare 把自有域名 CNAME 到 tunnel，即可用自定义域名 + 自动 TLS。
- Claude.ai 远程接入 MCP：`https://<你的域名或 *.trycloudflare.com>/mcp`。

> 完整部署 / 运维（环境变量、向量配置、保活、故障排查）见 [`docs/DEPLOY.md`](docs/DEPLOY.md)。

## 关键机制

- **衰减评分** —— 基于遗忘曲线的指数衰减 + 回想强化（情绪越强、越常被想起，衰减越慢）。
- **混合召回** —— 向量语义 + 关键词双通道，一致性加成融合（思想同 RRF），相关性主导 + 门槛式过滤。
- **晋升 / 结晶** —— 反复出现的感受聚类、提炼为稳定原则；源数据永不销毁，只降权、始终可检索。
- **角色自主生活** —— 后台 `日程 → 环境 → 快照 → 关系活动 → 事件` 闭环，产出的生活事件回流进记忆、可被对话引用。

## 未来功能展望

核心**记忆代谢机制**（晋升 → 合并 → 毕业）已落地。下一步把"陪伴"推向更立体的人机现实：

- 多模态现实接口，让角色走进用户的生活

- 主动消息机制（角色在合适时机主动发起）
- 多人共享同一角色，构建人机社会网络与关系知识图谱
- 独立前端
