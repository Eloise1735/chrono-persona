# chrono-persona

**给没有跨对话记忆的 AI Agent，装上一套会沉淀、会遗忘、会回想的长期记忆，并让角色拥有一条在对话间隙仍持续推进的「自主生活流」。**

让每次新对话不再从零重建，而是接续上一次；在没人对话时，角色的世界也仍在继续——从根源破解长期陪伴中的「互动同质化」。

## 核心产品判断

**1. 「记住太多」比「记住太少」更伤体验：**
业界常见方案是「全量存储 + 相似度召回」。然而大量储存导致的召回噪声不只会降低回忆质量，还会错误匹配语境导致对话扫兴，对长期体验的伤害大于偶尔遗漏。→ 选择**衰减 + 分层（事件 / 感受 / 稳定）+ 结晶**，对记忆做价值评估与优先级管理，而非全量召回。

**2. 防幻觉-未知即等待：**
早期后台会自动编排「角色与用户的互动」，但用户其实只在前台交互，导致后台「架空了用户」、破坏沉浸感。→ 立下硬约束：**绝不编造真实用户的行动 / 话语 / 位置**，未知即「等待」；确立 Agent 的**安全行为边界**。

**3. 生活流：破解互动同质化的根源：**
我判断「对话间隙的空白」才是同质化的真正根源，而非「功能不够多」。→ 用后台闭环（`日程 → 环境 → 快照 → 关系 → 事件`）让角色自主推进自己的一天，产出可被下次对话引用的「近况」。

**4. 对抗均值回归：引入外部变量：**
纯自生成的内容会向「安全、平庸、可预测」的均值收敛，越推进越像模板。→ 把**用户真实互动**作为权重最高的外部变量，反向重写角色日程，打断模型惯性。

## 功能一览

- **分层记忆** —— 事件 / 感受 / 稳定三层，各自的衰减与检索边界不同；稳定层豁免遗忘，内部再按 `standing`（必注入）/ `evolving`（按新近上浮）/ `anchor`（仅检索）细分。
- **角色自主生活流** —— 后台轮询推进 `日程 → 环境 → 快照 → 关系 → 事件` 闭环，带熔断保护，产出回流进记忆、可被对话引用。
- **记忆代谢** —— 衰减评分（遗忘曲线 + 回想强化）、混合召回（向量 + 关键词融合）、晋升 / 结晶（“稳定层-演化层-浮现层”三层管理，反复出现的感受提炼为稳定原则、定时消化事件获取关系近景、延缓遗忘主动召回的记忆事件）、相册机制（定时筛选出永不遗忘的珍贵记忆，并在每轮新对话注入记忆目录，高效获取核心信息）。

## 技术细节

### 架构

系统刻意拆成**两条互不耦合的线**：用户端·分层记忆（系统*记住*了什么）与角色端·自主生活（角色在两次对话之间*经历*了什么）。

**技术栈**：`MCP 客户端（Claude 等）⇆ FastAPI 服务 ⇆ {SQLite + Markdown 记忆桶 / 向量库 / 后台异步调度}`。检索走向量语义 + 关键词双通道混合融合；后台调度带熔断器，长期无人值守可用。

### 关键 Prompt 设计

- **生活流生成 prompt（防幻觉硬约束）**：强制「绝不编造真实用户的任何行动 / 话语 / 位置，未知即等待」，并要求 LLM 对本段自评（`speculative_about_user`），违规段落下游打标。
- **启动注入包（breath_bundle）**：固定槽位结构（个人 / 关系 / 自由联想），在「信息量 vs token 成本 vs 相关性」间平衡。
  
- **稳定原则注入**：`get_current_state` 把边界共识与关系原则注入上下文，区分「每轮必注入」与「按新近注入」。

### AI 调用逻辑

- **Function calling / 工具调用**：通过 MCP 工具集（约 20 个工具）让模型主动调用 `get_current_state` / `breath` / `hold` / `recall_anchors` 等完成记忆读写。
- **多模型 / OpenAI 兼容**：后台生成走 OpenAI 兼容 API，可切换 DeepSeek / Gemini / 任意兼容端点。
- **token 成本控制**：LLM 预算硬上限 + prompt-hash 去重 + 自动 token 统计与按模型单价的成本估算。
- **传输**：MCP Streamable HTTP / SSE；后台调度熔断器，连续失败自动暂停退避，避免故障时空转烧 token。

### 部署（含 DNS / HTTPS）

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml   # 填入 LLM api_base / api_key / model
python -m server.main                # 默认 :8000，含 Web 管理台 + MCP 端点
```

公网接入用 **Cloudflare Tunnel** 把本地 `:8000` 暴露到公网（自动 HTTPS、无需手动证书 / 开放端口）；DNS 把自有域名 CNAME 到 tunnel。Claude.ai 远程接入 MCP：`https://<域名>/mcp`。完整运维见 [`docs/DEPLOY.md`](docs/DEPLOY.md)。
